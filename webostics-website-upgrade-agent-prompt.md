# Webostics Website Upgrade – Master Agent Prompt

You are a senior UI/UX designer, product strategist, SEO specialist, and full-stack web developer.

I want you to completely redesign and modernize my existing website:

**https://webostics.com/**

The business/brand name is:

# WEBOSTICS

The existing website is an older digital-agency style website. I do **not** want a minor redesign. I want to transform Webostics into a modern hybrid platform combining:

1. Software / Web Development Services
2. E-commerce Development Services
3. Website & Business Solutions
4. IT / Deployment / DevOps Services
5. Technology Education & Courses
6. AI Training and Practical AI Use Cases

The website should make Webostics look like an experienced technology company **and** a practical technology-learning platform.

## Core Brand Concept

Webostics should communicate:

# BUILD • LEARN • LAUNCH

Possible positioning:

Webostics helps businesses build digital products while helping students, freelancers, entrepreneurs, and developers learn the technologies required to build and launch products themselves.

# Important Coding Rules

Write clean production-quality code.

Avoid huge monolithic files.

Use reusable components.

Separate:

- UI
- Data
- Business logic
- Configuration

Avoid inline styles unless justified.

Use CSS variables/design tokens.

Keep dependencies minimal.

Never add a dependency when native functionality is sufficient.

Do not break existing production functionality unnecessarily.

Keep backups or create changes in a separate branch when Git is available.

Document significant architectural decisions.
